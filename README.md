\# Optimization of an RRRP-Based Latching Mechanism for CubeSat Docking Adapter



\## Project Overview



This project presents the design and optimization of a planar RRRP-based latching mechanism for CubeSat docking applications. The work was carried out in the context of Mission Navika under the IIT Bombay Student Satellite Program.



A trajectory-based optimization framework was developed to synthesize linkage parameters satisfying:

\- seating accuracy,

\- axial and lateral misalignment tolerance,

\- monotonic inward/downward engagement motion,

\- geometric feasibility,

\- and motion transmission characteristics.



The optimization problem was formulated as a constrained nonlinear optimization problem and solved using Sequential Least Squares Programming (SLSQP).
